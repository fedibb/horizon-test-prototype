📋 Requirements from Mock Codebeamer

REQ-001
eSIM Profile Download - Vodafone
esim_profile_download
High Priority

Verify eSIM profile download from Vodafone SM-DP+ server with valid activation code. The TCU shall successfully download the profile, activate it, and confirm ICCID registration within 30 seconds.

MNO: Vodafone | Network: LTE | Timeout: 30s
REQ-002
eSIM Profile Download - T-Mobile
esim_profile_download
High Priority

Verify eSIM profile download from T-Mobile SM-DP+ server for 5G SA network. Profile must support 5G standalone connectivity and register within 45 seconds.

MNO: T-Mobile | Network: 5G SA | Timeout: 45s
REQ-003
Network Registration - 5G SA Fallback to LTE
network_registration
Medium Priority

Verify automatic network fallback behavior when 5G SA is unavailable. TCU shall attempt 5G SA registration, detect failure, and fallback to LTE within 60 seconds.

Primary: 5G SA | Fallback: LTE | Timeout: 60s

🎯 Template Philosophy

Templates = Patterns, Not Requirements

  • One template → Many requirements: The esim_profile_download template handles both Vodafone and T-Mobile tests
  • Requirements hold data: MNO, timeout, activation codes are in the requirement JSON
  • Templates hold logic: Test structure, validation, evidence capture in Jinja2
  • Change rarely, add thoughtfully: 2 templates serve 3 requirements (1.5 requirements per template)
Available Templates:
  • esim_profile_download.j2 - Handles all eSIM profile download tests (REQ-001, REQ-002)
  • network_registration.j2 - Handles all network registration tests (REQ-003)

🚀 How to Run the Prototype

Quick Start

  1. Generate Tests: python generator/generator.py
  2. Run Tests: pytest tests/ -v
  3. View Results: Open evidence/report.html
  4. Full Docker Demo: docker-compose up
